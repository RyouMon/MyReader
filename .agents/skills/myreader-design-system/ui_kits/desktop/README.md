# MyReader Desktop UI Kit

**Platform:** Tauri 2 (macOS, Windows, Linux)  
**Design width:** 1280px  
**Stack:** React + CSS vars from `../../colors_and_type.css`

## Screens
1. **Library** — book grid with sidebar, search, filter
2. **Reader** — full reading view with toolbar overlay
3. **Settings** — sync config, library path, appearance

## Components
- `Sidebar.jsx` — left nav with library modes
- `BookGrid.jsx` — responsive book cover grid
- `BookListItem.jsx` — compact list row
- `ReaderView.jsx` — reading surface with top/bottom toolbars
- `SyncStatus.jsx` — sync indicator chip
- `SettingsPanel.jsx` — settings layout

## Usage
Open `index.html` for the interactive prototype.
