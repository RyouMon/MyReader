# MyReader native Automerge backend

This internal React Native module runs Automerge in compiled Rust and exposes
the backend expected by `@automerge/automerge/slim`. It exists because Hermes
does not provide the global `WebAssembly` API required by Automerge's default
WASM backend.

MyReader installs `nativeApi` once through Automerge's `UseApi` hook, then keeps
using the public `@automerge/automerge` document API in the sync domain. The
mobile and desktop implementations both pin the Rust `automerge` crate to
`0.10.0`, so they exchange the same binary change format.

## Ownership

The UniFFI wrapper and generated bridge started from
[`react-native-automerge-generated`](https://github.com/klehmann/react-native-automerge-generated)
and are maintained in this repository for MyReader's required Automerge API.
The upstream Apache-2.0 license is retained in `LICENSE`.

Hand-maintained integration code lives in:

- `rust/`: the Rust wrapper and UniFFI contract;
- `src/useapi-adapter.ts`: the Automerge slim-backend adapter;
- `src/proxy.ts`: document proxy conversion;
- `src/index.ts`: React Native installation and exports.

Files below `src/generated/` and `cpp/generated/` are generated by
`uniffi-bindgen-react-native`.

## Supported scope

The adapter covers the document, change, incremental load/save, missing
dependency, merge, and sync operations used by MyReader's library-sidecar
domains. Methods outside that scope, including block APIs, `saveBundle`, and
`encodeChange`, remain unsupported and must not be introduced at a call site
without extending the adapter and its tests first.

## Native artifacts

Static libraries for iOS device, Apple Silicon iOS Simulator, and the supported
Android ABIs are generated locally and ignored by Git. A clean checkout must
generate or otherwise provide these artifacts before building the native app.

Regenerate them after changing Rust or the UniFFI contract:

```bash
pnpm --dir my-reader-mobile/modules/automerge-native build:ios
pnpm --dir my-reader-mobile/modules/automerge-native build:android
```

The scripts also regenerate the TypeScript, C++, Objective-C++, and Kotlin
bindings. Commit generated source changes, but not the native static libraries.

## Verification

```bash
cd my-reader-mobile/modules/automerge-native/rust
cargo test

cd ../../../..
pnpm --filter my-reader-mobile exec jest --runInBand
```

The real cross-device regression procedure is documented in
`docs/sync/reading-progress-cross-device-regression.md`.
