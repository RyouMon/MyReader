# 隐私与数据边界

MyReader 是 Local-First 阅读器，不要求注册 MyReader 账号，也不依赖官方内容或同步服务器。本文说明开源版本的默认行为；第三方自行构建和修改的版本可能不同。

## 保存在设备上的数据

- 书库注册、应用设置与 Reader 偏好；
- 设备侧缓存、下载的书籍与封面；
- 每书库的阅读进度、收藏、书签、高亮、笔记与阅读记录；
- WebDAV 密码、OneDrive token 等凭据（使用平台安全存储，不写入同步 sidecar）。

## 何时会连接第三方服务

只有在用户主动配置或使用相应能力时，MyReader 才会连接：

- **WebDAV**：向用户填写的服务器读取或写入书库文件与同步数据；
- **OneDrive**：通过 Microsoft 登录和 Graph API 访问用户授权的目录；
- **诊断信息（可选，默认关闭）**：官方发布的移动端构建会配置 `EXPO_PUBLIC_SENTRY_DSN`，使 Sentry 诊断功能可用，但错误上报默认关闭。只有用户在设置中主动打开「共享诊断信息」后，应用才会初始化 Sentry 并开始发送新发生的错误诊断。开启后，可能发送错误消息与堆栈、应用版本，以及设备与运行环境信息（如设备型号、操作系统）；当前配置不发送 Sentry Logs、不启用 Session Replay，也不允许 SDK 主动附加默认 PII。用户关闭开关后，不再采集新的 Sentry 诊断事件。第三方构建如未配置 DSN，该开关不可用。桌面端目前尚未接入 Sentry。

Sentry DSN 是供客户端提交事件的公开项目地址，可以包含在应用构建中，不等同于管理凭据。`SENTRY_AUTH_TOKEN` 可用于构建与源码映射上传，属于敏感凭据，不会包含在应用或仓库中。

MyReader 当前没有广告 SDK，也没有独立的产品分析或行为画像服务。WebDAV、Microsoft 和可选 Sentry 对收到的数据分别适用其自身隐私政策与账户设置。

## 用户控制

- 删除书库注册不一定删除外部或远程源文件；确认界面会说明实际范围。
- 应用内部 MyReader 书库由应用拥有，删除时可能同时删除完整书库容器。
- 删除数据源时，MyReader 会尝试清理该数据源保存在设备上的凭据，例如密码或访问令牌。这不会撤销第三方服务端的授权；如需撤销，请前往对应第三方服务的账户或授权管理页面操作。
