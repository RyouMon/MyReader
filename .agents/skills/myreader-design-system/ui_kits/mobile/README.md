# MyReader Mobile UI Kit

**Platform:** React Native / Expo (iOS + Android)  
**Design width:** 390px (iPhone 15 Pro)  
**Stack:** React + iOS frame starter component

## Screens
1. **Library** — book grid with tabs, search
2. **Reader** — full-screen reading with gesture tap zones
3. **Settings** — sync target, appearance, device name

## Usage
Open `index.html` for the interactive prototype inside an iOS frame.
