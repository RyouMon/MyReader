## 动画设计 — 书库网格浏览

动画整体基调：**柔和、不抢眼、像翻书页般自然**。避免跳跃感强的弹性动画，偏向平滑 ease-out 过渡，呼应温暖阅读氛围。

### 书籍卡片
```
cardEnter:    400ms ease-out [Y+20→0, α0→1] stagger+60ms     ← 网格加载时卡片依次浮入
cardHover:    250ms ease-out [Y0→-4, shadow↗md]               ← 悬浮时微微上浮 + 阴影加深
cardPress:    120ms ease-in  [S1→0.97]                         ← 点击按下微缩
cardRelease:  200ms ease-out [S0.97→1]                         ← 松开回弹
coverShine:   300ms ease    [overlay α0→0.04→0]               ← 悬浮时封面上掠过一层淡光
progressReveal: 300ms ease-out [W0→actual, α0→1]              ← hover 时进度条从左向右展开
```

### 侧边栏
```
sidebarExpand:   300ms ease-out [W64→240]                      ← 展开，内容区同步收缩
sidebarCollapse: 250ms ease-in  [W240→64]                      ← 折叠
navItemHover:    200ms ease    [bg→secondary, paddingLeft+4]   ← 导航项悬浮时背景变色+微右移
navItemActive:   150ms ease    [bg→primary/10%, borderLeft+3]  ← 当前选中项左侧出现色条
```

### 顶部工具栏
```
searchFocus:  200ms ease-out [border→primary, shadow+ring]     ← 搜索框聚焦时边框变主色+光环
searchBlur:   150ms ease-in  [border→input, shadow-ring]       ← 失焦还原
viewToggle:   200ms ease    [bg→secondary, S0.95→1]            ← 视图切换按钮过渡
sortDropdown: 250ms ease-out [Y-8→0, α0→1]                    ← 下拉菜单向下滑出
```

### 弹出卡片 / 右键菜单
```
popoverIn:  200ms ease-out [Y-6→0, α0→1, S0.96→1]            ← 弹层从上方淡入
popoverOut: 150ms ease-in  [Y0→-4, α1→0]                      ← 弹层消失
```

### 页面切换
```
pageTransition: 350ms ease-out [α0→1, X-12→0]                 ← 切换分类时主内容区左滑淡入
gridReflow:     300ms ease-out [layout-shift]                  ← 筛选/排序后网格重新排列
```

### 加载状态
```
skeleton:   1800ms ∞ ease-in-out [bg: muted↔secondary]        ← 骨架屏暖色呼吸
spinner:    1200ms ∞ linear [R360°]                            ← 加载旋转
coverLoad:  400ms ease-out [α0→1, blur4→0]                    ← 封面图加载完成从模糊到清晰
```

### 状态栏
```
syncPulse:  2000ms ∞×3 ease-in-out [α0.5→1→0.5]              ← 同步中指示灯呼吸
syncDone:   300ms ease-out [S0.9→1.1→1, α0→1]                ← 同步完成打勾弹出
```

### 设计原则总结

| 原则 | 说明 |
|------|------|
| 时长 | 大部分 200~350ms，不拖沓不急促 |
| 缓动 | 以 ease-out 为主，进入自然，结束干脆 |
| 交错 | 网格卡片 stagger 60ms，有节奏感但不会等太久 |
| 克制 | 没有弹跳、旋转等夸张动画，保持阅读器的安静感 |
| 反馈 | 所有可交互元素都有轻微的视觉反馈（hover/active/focus） |
