## 动效方案

**页面级过渡**
- 设置内容区进入：`300ms ease-out` [X+16→0, opacity 0→1]（切换设置项时）

**书库卡片**
- 列表加载：`250ms ease-out` 逐项淡入 [Y+8→0, opacity 0→1]，stagger 60ms
- hover：`150ms` [shadow 上浮，轻微 Y-1]
- 删除：点击确认后 `200ms ease-in` [X+8→0, opacity 1→0, height 收缩]

**添加书库表单**
- 展开/收起：`250ms ease-out` [height 0→auto, opacity 0→1]
- 输入框 focus：`150ms` [border-color → primary, ring 出现]
- 确认按钮：`120ms` 按下缩放 [scale 1→0.97→1]

**删除确认**
- 按钮变色 + 文字切换：`150ms`，需二次点击确认，防误操作

动效整体轻柔克制，符合阅读类应用的静谧感。可以开始生成 HTML 了吗？
