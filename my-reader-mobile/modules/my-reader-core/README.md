# MyReader Core React Native Adapter

This package exposes the shared Rust backend to React Native through generated UniFFI, JSI, and
TurboModule bindings. Rust owns the use cases, SQLite transactions, Automerge document, storage
transport, and scheduler policy. The mobile `services/core` layer only adapts platform values and
stable UI-facing DTOs.

## Ownership

- `rust/src/` is handwritten and defines the typed UniFFI API plus FFI-safe conversions.
- `src/generated/`, `cpp/bindings/`, `cpp/my-reader-core.*`, `ios/MyReaderCore.*`, and the Android
  TurboModule sources are generated by `uniffi-bindgen-react-native`.
- `src/NativeMyReaderCore.ts` is the generated React Native codegen specification.
- `build/` and `android/src/main/jniLibs/` contain local Rust binaries and are ignored by Git.

Do not edit generated sources by hand. After changing an exported Rust function or record, regenerate
and build the applicable platform from the repository root:

```bash
pnpm core:build-bindings:ios
pnpm core:build-bindings:android
pnpm core:build-bindings
```

`pnpm --filter my-reader-mobile ios` and `pnpm --filter my-reader-mobile android` run the matching
binding build automatically. EAS runs it in `eas-build-post-install`.

The workspace patch for `uniffi-bindgen-react-native@0.31.0-3` only exports the package's own
`package.json`. Its generated Android CMake resolves that subpath, while the published package
otherwise blocks it through `exports`.

Run the shared business and FFI tests separately:

```bash
cargo test -p my-reader-core -p my-reader-core-ffi
```

Then compile the consuming native app:

```bash
cd my-reader-mobile/ios
pod install
xcodebuild \
  -workspace myreadermobile.xcworkspace \
  -scheme myreadermobile \
  -sdk iphonesimulator \
  -configuration Debug \
  -destination 'generic/platform=iOS Simulator' \
  ARCHS=arm64 \
  ONLY_ACTIVE_ARCH=YES \
  CODE_SIGNING_ALLOWED=NO \
  build

cd ../android
./gradlew :app:assembleDebug
```

Measure the shared backend high-frequency paths with:

```bash
cargo run -p my-reader-core --release --example runtime_baseline -- 1000
```

The reference environment and results are recorded in
[`docs/my-reader-core-runtime-baseline.md`](../../../docs/my-reader-core-runtime-baseline.md).
